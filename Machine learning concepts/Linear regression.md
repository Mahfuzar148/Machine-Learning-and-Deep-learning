### 🔹 Linear Regression কী?

**Linear Regression** হলো Machine Learning-এর একটি **supervised learning algorithm**, যা দিয়ে আমরা কোনো **continuous value (সংখ্যা)** predict করি।

👉 সহজভাবে:

* Input (X) → Output (Y) এর মধ্যে সম্পর্ক বের করে
* একটি **straight line (linear relationship)** দিয়ে prediction করে

📌 Example:

* পড়ার সময় → পরীক্ষার নম্বর
* বয়স → বেতন
* বাড়ির সাইজ → দাম

---

### 🔹 Linear Regression-এর মূল equation

[
y = mx + c
]

👉 এখানে:

* **y** = predicted value
* **x** = input feature
* **m** = slope (relationship কত strong)
* **c** = intercept

---

### 🔹 Types of Linear Regression

#### 1. Simple Linear Regression

* শুধু **১টা input feature**
* Example: Experience → Salary

#### 2. Multiple Linear Regression

* একাধিক feature
* Example: Size + Location + Rooms → House Price

---

### 🔹 Model কীভাবে কাজ করে?

1. Data collect করা
2. Best-fit line খুঁজে বের করা
3. Error minimize করা (Loss function)
4. Prediction করা

👉 Goal:
**Actual value আর predicted value এর difference কমানো**
