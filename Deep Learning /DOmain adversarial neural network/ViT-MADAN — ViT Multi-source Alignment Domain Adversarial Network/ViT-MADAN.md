# 1) `backbone(x)` → র’ ফিচার বের হয়

**কি হয়:**

* ইনপুট ইমেজ `x` (শেপ: **B×3×224×224**) ViT ব্যাকবোনে যায়।
* ViT ছবিটাকে প্যাচে ভেঙে **Self-Attention** দিয়ে গ্লোবাল কনটেক্সট শিখে **একটা ফিচার ভেক্টর** দেয়।
* কোডে হেড (`.head`) **Identity** করে রাখা, তাই ব্যাকবোন সরাসরি **ফিচার** রিটার্ন করে (ক্লাসিফিকেশন নয়)।

**শেপ উদাহরণ:**

* ধরা যাক ব্যাকবোন আউটপুট ডাইমেনশন **feature\_dim=768**।
* তাহলে `features` = **B×768** (কোডে 2D না হলে ফ্ল্যাট করা হয়)।

**কেন দরকার:**

* প্রিট্রেইনড ViT → ছবির থেকে **রিচ/জেনারাল** ফিচার দেয়; ছোট ডেটাতেও দ্রুত কনভার্জেন্স।

**খেয়াল রাখুন:**

* প্রিট্রেইনড ব্লকগুলো প্রথমে **freeze**, শেষের কয়েকটা ব্লক **unfreeze** করে fine-tune—এটাই কোডে করা।

# 2) `DomainAlignment(features, domain_labels)` → কমন স্পেসে align

**কি হয়:**

* **shared transform:** `Linear→BN→ReLU` দিয়ে সব ডোমেইনের জন্য একই ট্রান্সফরমেশন।
* **domain-specific bias (train+labels থাকলে):** স্যাম্পলটা যে ডোমেইনের, সেই ডোমেইনের **শুধু একটা bias ভেক্টর** যোগ করা হয়।
* **shared projection:** আবার `Linear→BN→ReLU` দিয়ে শেয়ারড স্পেসে প্রজেক্ট করা হয়।

**ফর্মুলা (সিম্পল):**

```
t1 = SharedTransform(features)                  # B×F
t2 = t1 + domain_bias[domain_id]                # B×F  (train+labels থাকলে)
aligned = SharedProjection(t2)                  # B×F
```

**শেপ:** ইনপুট **B×F** → আউটপুট **B×F** (F = feature\_dim)

**কেন দরকার:**

* ভিন্ন ডোমেইনের ফিচার **একই ধরনের স্পেসে** আনতে (domain shift কমাতে) — প্যারামিটার-এফিশিয়েন্ট উপায়ে।
* বড় আলাদা নেটওয়ার্ক না বানিয়ে **ছোট bias** দিয়েই ডোমেইনভেদে হালকা অ্যাডজাস্টমেন্ট।

**খেয়াল রাখুন:**

* `domain_labels` না থাকলে/`eval()` এ bias যোগ হয় না; তখন শুধু shared ট্রান্সফরমেশনই কাজ করে।

# 3) `FeatureBottleneck(aligned_features)` → ছোট, পরিষ্কার ফিচার

**কি হয়:**

* দুই ধাপের `Linear→BN→ReLU→Dropout`:

  1. **in\_dim → 2×bottleneck\_dim**
  2. **2×bottleneck\_dim → bottleneck\_dim**
* মানে আগে একটু **এক্সপান্ড**, পরে **কমপ্রেস** → গুরুত্বপূর্ণ তথ্য রেখে **নোইজ/স্পিউরিয়াস** অংশ বাদ দেয়া সহজ হয়।

**শেপ উদাহরণ:**

* ইনপুট `B×768` → আউটপুট `B×512` (যদি `bottleneck_dim=512`)

**কেন দরকার:**

* **রেগুলারাইজড, কমপ্যাক্ট** ফিচার → পরের ক্লাসিফায়ার/ডিসক্রিমিনেটর কম প্যারামে, বেশি স্টেবল।
* ওভারফিটিং কমে (BN+Dropout), adversarial ট্রেনিংও স্থির হয়।

**খেয়াল রাখুন:**

* নতুন লেয়ার ইনিট: Xavier/Glorot + BN γ=1, β=0 (কোডে `apply(init_weights)` করা)।

---

# 4) `(train হলে) mixup_features(bottleneck_features)` → ফিচার রেগুলারাইজ

**কি হয়:**

* ব্যাচের ভেতর **র‌্যান্ডম পারমুটেশন** নিয়ে ফিচার মিক্স করা হয়:

  $$
  x_{\text{mix}} = \lambda x + (1-\lambda) x_{\text{perm}},\quad \lambda \sim \text{Beta}(\alpha,\alpha)
  $$
* এতে মডেল **স্মুথ ডিসিশন বাউন্ডারি** শেখে, ছোট ডেটায়ও জেনারেলাইজেশন ভালো হয়।

**শেপ:** `B×bottleneck_dim` → `B×bottleneck_dim` (একই শেপ থাকে)

**খেয়াল রাখুন:**

* ব্যাচ সাইজ < 2 হলে মিক্সআপ **স্কিপ**।
* এখানে শুধু **ফিচার** মিক্স হয়েছে; **লেবেল মিক্স** হয়নি—কোডে আলাদা লেবেল-মিক্স না করে label smoothing ব্যবহার করা হয়েছে (এটাও এক ধরনের রেগুলারাইজেশন)।

---

# 5) `Classifier(mixed_features)` → `logits`

**কি হয়:**

* `Linear→BN→ReLU→Dropout → Linear→BN→ReLU→Dropout → Linear`
* শেষের `Linear` → **num\_classes** (যেমন 2) লজিটস দেয়।

**শেপ উদাহরণ:**

* ইনপুট `B×512` → আউটপুট `B×2` (binary হলে)

**কেন দরকার:**

* বটলনেক ফিচার থেকে **চূড়ান্ত সিদ্ধান্ত** (real/fake ইত্যাদি) বের করা।

**খেয়াল রাখুন:**

* লস হিসেবে কোডে `cross_entropy(..., label_smoothing=0.1)`—স্মল ডেটায় **ভালো ক্যালিব্রেশন** ও ওভারফিটিং কমাতে হেল্প করে।

## (বোনাস) ডোমেইন-অ্যাডভার্সেরিয়াল শাখা কী করে?

* বটলনেক ফিচার → **সামান্য noise** → **GRL(α)** → **DomainDiscriminator** → `domain_pred`।
* GRL backward-এ **নেগেটিভ গ্র্যাড** পাঠায় → ফিচার এক্সট্রাক্টরকে **ডোমেইন-ইনভারিয়্যান্ট** বানাতে বাধ্য করে।
* অতিরিক্ত **confusion loss (KL to uniform)** আছে—ডিসক্রিমিনেটরকে ইচ্ছাকৃতভাবে **অস্পষ্ট** রাখতে, যাতে ফিচারগুলো ডোমেইন-নিরপেক্ষ হয়।
* α (GRL strength) আর λ (ডোমেইন লস ওজন) **ধীরে ধীরে বাড়ে**—শুরুতে ট্রেনিং স্টেবল রাখতে।

## কেন এই পুরো চেইনটা কাজের?

* **ViT backbone**: শক্তিশালী প্রিট্রেইনড ফিচার
* **DomainAlignment**: ডোমেইন শিফট কমে → সব সোর্স/টার্গেটে কমন স্পেস
* **Bottleneck**: কমপ্যাক্ট + রেগুলারাইজড ফিচার → ক্লিন ডিসিশন
* **Mixup + label smoothing**: জেনারেলাইজেশন/ক্যালিব্রেশন ভালো
* **Adversarial branch (GRL + Discriminator + Confusion)**: ফিচারকে **ডোমেইন-ইনভারিয়্যান্ট** করে
