### 1) অ্যালাইনমেন্টের আগে: ফিচারগুলো ডোমেইনভেদে ছড়ানো

```
              (Feature space: BEFORE alignment)

        Domain A                 Domain B                 Domain C
      o  o   oo o               x   xx x               + +   +  + +
       o   o  o                  x   x  x               +  + + +   +
      o o   o  o                x  x   x                 + +   + +
           o o                    x  x                          +

    (A= ক্যামেরা A, B= ক্যামেরা B, C= ক্যামেরা C; ক্লাস্টারগুলো দূরে দূরে)
```

* প্রতিটি চিহ্ন (o/x/+) = একেকটা স্যাম্পলের ফিচার।
* দেখা যাচ্ছে A/B/C **আলাদা ক্লাস্টার**—ডোমেইন শিফট বেশি।

---

### 2) অ্যালাইনমেন্টের ধাপ (একটি স্যাম্পলের পথ)

```
features
   |
   |  Shared transform  (Linear + BN + ReLU)   # সবার জন্য একই বদল
   v
t_shared
   |
   |  + domain-specific bias (train + label)   # যেটা যে ডোমেইনের, তার ছোট্ট bias যোগ
   v
t_biased
   |
   |  Shared projection (Linear + BN + ReLU)   # আবার সবার জন্য একই প্রজেকশন
   v
aligned_features   # কমন/শেয়ারড স্পেসে বসে গেল
```

---

### 3) অ্যালাইনমেন্টের পরে: সব ডোমেইন একই কমন স্পেসে

```
              (Feature space: AFTER alignment)

                      o  x  +   o  +  x
                   +   o   x  +  x   o   +
                    x  +  o   +  o   x
                      +   o  x   +  x
                         o  +   x

            (A/B/C—তিনটাই এখন প্রায় একই ক্লাস্টারে মিশে গেছে)
```

* এখন ক্লাসিফায়ারের কাজ সহজ—ডোমেইন নয়, **ক্লাসের সংকেত**ের দিকে ফোকাস করতে পারে।

---

### 4) খুব ছোট ফর্মুলা ভাবনায়

```
t1 = SharedTransform(features)           # সব ডোমেইনের জন্য একই
t2 = t1 + domain_bias[domain_id]         # A/B/C অনুযায়ী ছোট শিফট
aligned = SharedProjection(t2)           # কমন স্পেসে বসানো (আকার একই থাকে)
```

---

### 5) এক লাইনে সারাংশ

**Domain Alignment** = আগে **সবার জন্য একই ট্রান্সফরম**, তারপর **ডোমেইনভিত্তিক ছোট bias**, শেষে আবার **সবার জন্য একই প্রজেকশন**—ফলে ভিন্ন ডোমেইনের ফিচার **একই ধাঁচে** এসে **ডোমেইন শিফট কমে** যায়।
