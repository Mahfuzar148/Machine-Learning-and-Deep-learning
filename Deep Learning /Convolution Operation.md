# **Convolution Operations – পূর্ণ ডকুমেন্টেশন**

## 1. ভূমিকা

Convolution হলো একটি গাণিতিক অপারেশন, যেখানে একটি **Kernel (Filter)** ইনপুট ডেটার উপরে স্লাইড করে (stride দিয়ে) এবং প্রতিটি স্থানে **element-wise multiplication + summation** করে নতুন আউটপুট ভ্যালু তৈরি করে।
Deep Learning-এ এটি মূলত ফিচার বের করার জন্য ব্যবহৃত হয়, যেমন ইমেজে এজ, টেক্সচার, অবজেক্টের আকার ইত্যাদি।

---

## 2. মৌলিক কনসেপ্ট

### 2.1 Kernel (Filter)

* একটি ছোট আকারের ওজন ম্যাট্রিক্স (যেমন 3×3, 5×5), যেটা পুরো ইনপুটের উপর স্লাইড করে।
* এই ওজনগুলো **লার্নেবল প্যারামিটার**, ট্রেনিং চলাকালে আপডেট হয়।

### 2.2 Stride

* Kernel প্রতি ধাপে কত পিক্সেল/পজিশন এগোবে।
* Stride = 1 → প্রতিবার এক ধাপ, Stride = 2 → প্রতিবার দুই ধাপ।

### 2.3 Padding

* Kernel যাতে ইনপুটের বর্ডার অংশেও কাজ করতে পারে, এজন্য চারপাশে **zero (বা অন্য মান)** যোগ করা হয়।

---

## 3. Conv1D

### 3.1 ডেটা টাইপ

* 1D সিকোয়েন্স: টাইম সিরিজ, অডিও waveform, টেক্সট এম্বেডিং।

### 3.2 ইনপুট শেপ

```
[batch_size, channels, length]
```

* **channels**: টাইম সিরিজে ফিচারের সংখ্যা
* **length**: সিকোয়েন্সের দৈর্ঘ্য

### 3.3 কর্ণেল মুভমেন্ট

* শুধুমাত্র length dimension বরাবর।

### 3.4 উদাহরণ

```python
nn.Conv1d(in_channels=1, out_channels=16, kernel_size=3, stride=1, padding=1)
```

* ইনপুটে 1 চ্যানেল, আউটপুটে 16 ফিচার ম্যাপ।

### 3.5 ব্যবহার ক্ষেত্র

* অডিও ক্লাসিফিকেশন
* সেন্সর সিগন্যাল অ্যানালাইসিস
* এনএলপি (character-level features)

---

## 4. Conv2D

### 4.1 ডেটা টাইপ

* ইমেজ, 2D ফিচার ম্যাপ।

### 4.2 ইনপুট শেপ

```
[batch_size, channels, height, width]
```

* **channels**: RGB ছবিতে 3, বা ফিচার ম্যাপে অন্যান্য সংখ্যা
* **height, width**: ছবির স্পেশিয়াল ডাইমেনশন

### 4.3 কর্ণেল মুভমেন্ট

* Height এবং Width উভয় দিকেই স্লাইড করে।

### 4.4 উদাহরণ

```python
nn.Conv2d(in_channels=3, out_channels=64, kernel_size=3, stride=1, padding=1)
```

* 3-চ্যানেলের ইনপুট ইমেজ → 64 আউটপুট ফিচার ম্যাপ।

### 4.5 ব্যবহার ক্ষেত্র

* ইমেজ ক্লাসিফিকেশন
* অবজেক্ট ডিটেকশন
* ইমেজ সেগমেন্টেশন

---

## 5. Conv3D

### 5.1 ডেটা টাইপ

* ভিডিও বা 3D ভলিউমেট্রিক ডেটা (যেখানে Depth বা Time ডাইমেনশন আছে)।

### 5.2 ইনপুট শেপ

```
[batch_size, channels, depth, height, width]
```

* **depth**: ভিডিও ফ্রেম সংখ্যা বা ভলিউমেট্রিক স্লাইস সংখ্যা
* **height, width**: প্রতিটি ফ্রেম/স্লাইসের আকার

### 5.3 কর্ণেল মুভমেন্ট

* Depth, Height, Width — তিন দিকেই স্লাইড করে।

### 5.4 উদাহরণ

```python
nn.Conv3d(in_channels=3, out_channels=32, kernel_size=(3,3,3), stride=1, padding=1)
```

* 3-চ্যানেলের ভিডিও ইনপুট → 32 আউটপুট ফিচার ম্যাপ।

### 5.5 ব্যবহার ক্ষেত্র

* ভিডিও অ্যাকশন রিকগনিশন
* মেডিক্যাল ইমেজিং (MRI, CT Scan)
* 3D অবজেক্ট ডিটেকশন

---

## 6. তুলনামূলক সারসংক্ষেপ

| টাইপ   | ইনপুট শেপ         | মুভমেন্ট ডাইমেনশন    | সাধারণ ব্যবহার   |
| ------ | ----------------- | -------------------- | ---------------- |
| Conv1D | `[B, C, L]`       | Length               | টাইম সিরিজ, অডিও |
| Conv2D | `[B, C, H, W]`    | Height, Width        | ইমেজ             |
| Conv3D | `[B, C, D, H, W]` | Depth, Height, Width | ভিডিও, 3D ডেটা   |

---

## 7. বাস্তব উদাহরণ: ৩ ধরণের Conv একসাথে

```python
import torch.nn as nn

conv1 = nn.Conv1d(1, 16, 3, stride=1, padding=1)
conv2 = nn.Conv2d(3, 64, 3, stride=1, padding=1)
conv3 = nn.Conv3d(3, 32, (3,3,3), stride=1, padding=1)
```

* **conv1** → 1D সিগন্যাল প্রসেসিং
* **conv2** → ইমেজ প্রসেসিং
* **conv3** → ভিডিও বা ভলিউম প্রসেসিং

## 1️⃣ Feature Extraction মানে কী

Feature Extraction মানে হচ্ছে **কাঁচা ইনপুট ডেটা (যেমন ছবি, অডিও, ভিডিও) থেকে দরকারী প্যাটার্ন, স্ট্রাকচার, বা বৈশিষ্ট্য বের করা**।

* উদাহরণস্বরূপ, ইমেজে:

  * নিচের লেয়ারে → এজ, কর্নার, টেক্সচার
  * মাঝারি লেয়ারে → শেপ, প্যাটার্ন
  * উপরের লেয়ারে → অবজেক্টের উচ্চস্তরের ধারণা (যেমন মুখ, গাড়ি ইত্যাদি)

---

## 2️⃣ Convolution কীভাবে Feature Extract করে

1. **Kernel (Filter)**: ছোট মাপের ওজন ম্যাট্রিক্স, যা ইনপুটের ওপর স্লাইড করে।
2. **Element-wise Multiplication + Sum**: প্রতিটি লোকেশনে কর্ণেল ও ইনপুট প্যাচ মিলিয়ে নতুন মান বের হয়।
3. **ফিল্টারের ভিন্ন ভিন্ন ওজন** → ভিন্ন ভিন্ন বৈশিষ্ট্য বের করতে সক্ষম হয়।
4. একাধিক ফিল্টার → একসাথে একাধিক ধরনের ফিচার এক্সট্রাক্ট করে।

---

## 3️⃣ কেন এটা শক্তিশালী

* **Local connectivity**: একসাথে পুরো ইনপুটের দিকে না তাকিয়ে ছোট ছোট এলাকায় কাজ করে।
* **Weight sharing**: একই ফিল্টার পুরো ইনপুটে প্রয়োগ হয়, ফলে প্যারামিটার সংখ্যা কমে।
* **Translation invariance**: অবজেক্ট কোথায় আছে তার চেয়ে, *কি প্যাটার্ন আছে* সেটাই বেশি গুরুত্বপূর্ণ হয়ে যায়।

---

## 4️⃣ Conv1D / Conv2D / Conv3D তে Feature Extraction

* **Conv1D**: টাইম-সিরিজ বা সিকোয়েন্সে নির্দিষ্ট টাইম উইন্ডো থেকে প্যাটার্ন বের করে।
* **Conv2D**: ইমেজের ছোট ছোট স্পেশিয়াল রিজিয়ন থেকে প্যাটার্ন বের করে।
* **Conv3D**: ভিডিও বা 3D ডেটা থেকে *স্পেশিয়াল + টেম্পোরাল* ফিচার একসাথে বের করে।

---

## 5️⃣ সারসংক্ষেপ

Convolution লেয়ার হচ্ছে **feature detector**, আর নিউরাল নেটওয়ার্কের পরবর্তী লেয়ারগুলো সেই ফিচার ব্যবহার করে সিদ্ধান্ত নেয়।
আপনি এটাকে ভাবতে পারেন — কাঁচা ডেটা থেকে “দূরবীন” দিয়ে গুরুত্বপূর্ণ অংশগুলো বেছে আনা।
